# 标题句式与题材策略

## 搬运标题的第一问题

原视频的标题是写给「已经认识作者 / 已经看过这部作品」的人看的。B 站观众多半两个都不满足。

所以搬运标题要做的不是翻译，是**补上前置条件**：这是什么作品、这是谁、看这个我能得到什么。补不进去，标题就只是自娱自乐。

例：`psychology of NATE THE GREAT ｜ therapist breakdown of Ted Lasso character`
直译成「Nate 大帝的心理学｜心理师解析泰德·拉索角色」几乎没人点。B 站上要说「《足球教练》」而不是「泰德·拉索」，而且得讲清观众能拿到什么。

## 三个入口，一个标题

| 入口 | 观众怎么遇到你 | 标题要负责的事 |
|---|---|---|
| 推荐流 | 刷首页 | 前 18 个字抓人，和封面配合成一个完整钩子 |
| 搜索 | 主动搜作品名 / 人物名 / 问题 | 标题里必须有那个会被搜的词，原样出现 |
| 关注动态 | 老观众 | 系列感，让人知道这是第几期、讲什么 |

一个好标题通常三者都占一点。只占推荐的，播放高但吃完就散；只占搜索的，长尾稳但起量慢。

## 本地化三件事

1. **译名用中文圈通行的那个**。Ted Lasso → 《足球教练》，不是《泰德·拉索》。查不到通行译名，就用描述性说法（「苹果那部讲足球教练的剧」），别自己音译一个。
2. **人名第一次出现带身份**。「Nate」对观众是空的，「被 Ted 一手提拔的那个助理教练」才有信息。
3. **数字和单位换成能直观看懂的**。「earned 5 figures」写成「一个月挣到五位数」比写具体美元数更有效。

## 六类钩子（正好对应 6 个候选）

每类出一个，不要 6 个都是同一类的变体。

| 类型 | 干什么 | 例子 | 适合 |
|---|---|---|---|
| 反常识 | 打破观众已有判断 | 他越努力讨好，越被当成笑话 | 影评、心理、观点 |
| 具体数字 | 给一个可预期的量 | 3 个细节，说明 Nate 从小就没被当回事 | 解析、清单、方法 |
| 冲突对峙 | 把两个东西摆到对面 | Ted 从不夸人，Nate 要的就是那句夸奖 | 人物、剧情、争议 |
| 归因解释 | 回答一个「为什么」 | Nate 为什么恨 Ted？答案在他爸身上 | 科普、心理、深度 |
| 情绪共鸣 | 让观众想到自己或身边的人 | 你身边那个突然翻脸的人，可能忍了很久 | 心理、职场、生活 |
| 结论前置 | 直接把判断甩出来 | 一个讨好型人格的崩塌，分四步 | 观点、总结 |

## 句式库

写完对照一遍，能换更强的就换。所有句式的前提是**内容撑得住**，撑不住就是标题党，掉完播还会被举报。

| 句式 | 模板 | 说明 |
|---|---|---|
| 归因 | `X 为什么 Y？答案在 Z` | Z 是视频真讲的东西，别卖关子卖到反悔 |
| 反转 | `X 的真正问题，不是 Y` | 否定的部分要真被推翻过 |
| 对照 | `不是 A，是 B` | A 要是观众本来以为的那个 |
| 代价 | `他做了 X，代价是 Y` | 有具体后果才有分量 |
| 量化 | `N 个细节 / 3 个信号` | 数字要真在视频里数得出来 |
| 身份 | `一个<身份>的<结局>` | 身份越具体越好，「讨好型人格」优于「内向的人」 |
| 悬念 | `直到那一刻，一切都变了` | 必须真的有一个「那一刻」 |
| 观点 | `一句话：……` | 观点要够狠，软话不如不说 |

## 结构怎么排

三种，按内容选：

- **钩子 + 限定**：`他越努力讨好，越被当成笑话｜《足球教练》Nate 心理线`。抓人优先，搜索词垫后。
- **限定 + 钩子**：`《足球教练》Nate：一个讨好型人格的崩塌过程`。搜索优先，适合作品名有搜索量的时候。
- **纯钩子**：`你身边那个突然翻脸的人，可能忍了很久`。共鸣优先，不依赖作品名，但天花板低。

字数：20–40 最稳。超 40 字手机端会截，截掉的部分等于没写。

## 反例

| 别这样 | 为什么 | 改成 |
|---|---|---|
| 直译原题 | 观众不认识作者和作品 | 补前置条件或只讲收益 |
| `The Unpredictable Genius of Ted Lasso_burned` | 文件后缀混进标题，一眼机器搬运 | 删掉 `_burned` / `_bilingual` 和全角 `｜` |
| 标题里塞满标签词 | 读起来像 SEO 垃圾 | 核心词出现一次就够 |
| 六个候选都是「为什么」 | 等于只有一个候选 | 六类钩子各出一个 |
| 承诺视频里没有的东西 | 掉完播、被举报 | 兑现检查后再定 |
