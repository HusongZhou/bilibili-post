# B 站投稿字段与红线

数字来自 2026-11 的投稿页（创作中心）实测和公开规则。**投稿页当场提示的为准**，这里过期了就以页面为准。

## 字段硬限制

| 字段 | 上限 | 建议 | 备注 |
|---|---|---|---|
| 标题 | 80 字（投稿页有 44/80 这样的实时计数） | 20–40 字 | 手机列表大约前 18–22 字可见，后面被截断 |
| 简介 | 2000 字 | 300–800 字 | 折叠前只显示前两行 |
| 标签 | 10 个 | 10 个打满 | 已有 3 个时页面提示「还可以添加 7 个」 |
| 封面 | 必填 | 16:10，1146×717（高清 1920×1200） | 手机端上下会被裁，文字别贴边 |
| 分区 | 必填（带红色星号） | 二级分区选准 | 分区错了直接掉推荐池 |
| 创作声明 | 必填（带红色星号） | 见下 | 转载必须在这选「转载」 |

投稿页的字段顺序是：封面 → 标题 → 创作声明 → 分区 → 标签 → 简介。投稿包按这个顺序写，复制起来最省事。

## 转载规则

这几条是硬规则，不是风格问题：

- 搬运 / 转载的稿件，投稿类型必须选**转载**，并填写来源链接、原作者、原标题。
- 《bilibili 投稿公约》明确：**未获得原作者授权、自行翻译并添加字幕，不算自制**。加了中文字幕依然是转载。
- 转载侵权（原作者投诉）会按社区规则处理，可能下架甚至封号。
- 简介里注明来源不违规，但也**不能代替**投稿类型选「转载」。
- **不要编造授权**。没有授权就写「转载自 XX，仅供学习交流，侵删」这类如实表述，不要写「已获授权」。

转载声明模板（放在简介靠后位置）：

```
本视频转载自 YouTube 频道 <频道名>《<原标题>》（<发布日期>）
原视频：<链接>
中文翻译与字幕由本频道制作，仅供学习交流；如涉版权请联系删除。
```

## 标题红线

下面这些词和句式会被判标题党或违反广告法，直接影响推荐甚至审核：

| 类别 | 例子 | 为什么 |
|---|---|---|
| 标题党 | 震惊、速看、必看、99% 的人不知道、速进 | 平台明文禁止的诱导性表述 |
| 极限词 | 最、第一、唯一、顶级、国家级、永久、根治、百分百 | 广告法极限用语 |
| 虚假承诺 | 「看完就能学会」「三天搞定」 | 标题与内容不符，掉完播率还可能被举报 |
| 站外引流 | 微信、QQ、公众号、群号、二维码 | 站内禁止导流 |
| 医疗断言 | 治愈、确诊、药到病除 | 健康类内容的高危表达 |

安全做法：把「震惊」换成具体事实，把「最」换成可验证的限定（「我见过的」），把「必看」换成「值得看的两点」。

## 分发放大器

同样的内容，这几个地方做了能多拿一截流量：

- **标签前 3 个会同步生成动态话题**，最有价值的词放前面。
- **参与话题**：投稿页会给「影视未来星企划」「AI 整活全宇宙」这类活动话题，贴合就挂上，有额外流量池。
- **推荐标签**：投稿页按内容给的候选，贴合的优先用，比生造词准。
- **合集**：搬运号最该做的，追更能把一次性流量变成关注。
- **置顶评论**：一个具体问题比「求三连」管用。

## 分区怎么选

拿不准时按「观众想看什么」选，不是按「视频是什么」选：

| 观众进来想 | 常见分区 |
|---|---|
| 学到知识 / 方法 | 知识 → 科学科普、校园学习、人文历史、社科·法律·心理 |
| 看数码 / 科技 | 科技 → 数码、计算机技术、机械 |
| 看影视解说 / 杂谈 | 影视 → 影视杂谈、影视整活、影视剪辑 |
| 看纪实 / 人物 | 纪录片 → 纪录片 |
| 看乐子 | 娱乐 / 搞笑 |
| 学英语 | 知识 → 校园学习 |

分区名称和层级平台会调整，**以投稿页下拉列表为准**；给建议时说明这是建议，不要说得像确定的事。
